## Ralph loop setup

The Ralph loop (`ralph/loop.sh`) reads `ralph/PROMPT.md`, picks the top item in
`ralph/BACKLOG.md`, implements one tested change, commits green, and repeats.

Recommended setup:

1. Separate workspace (do **not** run Ralph on the live `/opt/hl-bot` tree):
   ```bash
   sudo -u hlbot bash
   cd /opt
   git clone https://github.com/laqaer/hl-bot.git hl-bot-ralph
   cd hl-bot-ralph
   git checkout -b claude/ralph-auto
   ```
2. Ensure `claude` CLI is authenticated for the `hlbot` user.
3. Run under tmux/systemd with `RALPH_PUSH=1` so CI auto-merges green increments.
4. Enable `hlbot-deploy.timer` on the live host to pick up merged `main`.

Safety: the loop is forbidden from live trading, gate weakening, or touching KILL.
